# catherine

> cat, from *categories* — the small cat, not the whole zoo.

A browser-runnable, agent-usable category-theory modeling workbench: a
small deterministic kernel that takes a model document (schema +
instance as JSON), executes its declared constraints, and returns
finding-typed diagnostics with witnesses — callable from a CLI by
agents and openable in a browser by humans.

- Repository: <https://github.com/arltificial/catherine>
- Releases: <https://github.com/arltificial/catherine/releases>
- CLI crate: `catherine-cli` (binary: `catherine`)

Start with [Using catherine](./USING.md), then [Design](./DESIGN.md)
and [Theory](./THEORY.md).
